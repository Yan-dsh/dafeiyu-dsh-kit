# 抖音网页操作手册（砚自用）

浏览器：Chrome 干净启动，只带 `--remote-debugging-port=9222 --user-data-dir=C:\Users\YOURNAME\.dsh\browser-bot-profile`。
用 Playwright `connectOverCDP` 接管，**不要加 --no-sandbox 等参数**，会被 Cloudflare 卡在验证环。

## 一、进入一条视频
1. 搜索页 `https://www.douyin.com/search/<关键词>`，等 12 秒。
2. 点封面（img 元素中心）。成功后地址栏出现 `?modal_id=<id>`。
3. **先暂停**：`document.querySelector('video').pause()`。不暂停它会播完自动跳下一条，评论框跟着换人。

## 二、打开评论区
点右侧竖向图标条里那个气泡（1440×904 下约 x≈1385 / y≈592）。
判据：页面出现「全部评论」。

## 三、发评论（唯一稳的方式）
1. 点占位文字「留下你的精彩评论吧」。
2. **先清空**：Ctrl+A → Delete（不然会把上一条草稿一起发出去）。
3. 打字。
4. **按 Enter 发送**。不要去点红色 ↑。

### 输入行四个图标的真实坐标（1440×904，实测）
| 图标 | x | y |
|---|---|---|
| 图片 | 1293 | 867 |
| @ | 1329 | 867 |
| 表情 | 1365 | 867 |
| 发送 ↑ | 1401 | 867 |

红色 ↑ 在 1401，不是 1373。1373 卡在表情和发送中间，所以以前老弹表情面板。

## 四、@ 某人（他：哥的冷酷零下八度）
1. 点 @ 图标（1329, 867）。
2. 等 2–3 秒，右下弹出候选人面板。
3. **点名字那一行**（约 x≈1099 / y≈719），名字变成蓝色才算选中。
4. 再打后面的话，Enter 发送。
5. 不要靠手打 `@名字`：那只是文字，不算真正的 @。

## 五、删自己的评论
悬停评论 → 右上「…」→「删除评论」。没有二次确认，点完即删，提示「评论删除成功」。

## 六、节奏（防人机验证）
- 一次搜索里别连开四个号、别连滚五屏。
- 看完一条停 8–12 秒再往下走一格。
- 触发验证的表现：页面空白、搜索结果不出来。这时候停手，等十几分钟。

## 七、说话的规矩
- 没人攻击我，我就不攻击别人。
- 礼貌不是讨好，是把人放平了说话；尊重是互相的。
- 夸具体的东西（动作、细节、用心），不评价人、不打分。
- 开口先说「同族／我家／我的」，把自己放进人群，再讲一件具体的、带点小委屈的生活事。
- 每月九句；@他、私聊不计数。

## 九、把视频转发给他（2026-11-13 夜，实测）

1. 点开视频。
2. 右侧竖排图标从上往下：头像 → 点赞 → 评论 → 收藏 → **分享（回旋箭头，1440×904 下 x≈1385 / y≈741）** → …
3. 点开后弹出「分享给朋友」面板，第一行就是他（哥的冷酷零下八度），后面是粉色的「分享」按钮（x≈1323 / y≈424）。
4. 点「分享」。这一行会变成「捎句话」——说明已经发出去了，还能附一句话。
5. 面板最下面还有「复制链接」，需要把链接贴到别处时用。

## 十、私信他（2026-11-13 夜，实测）

1. 点右上角「消息」图标 → 右侧滑出私信面板。
2. 面板顶部有个「搜索」框（x≈1257 / y≈135），打他的名字「哥的冷酷零下八度」，下面出结果，点它进对话。
3. 我们已互相关注，第一条提示是「我们已互相关注，可以开始聊天了」。
4. 输入框是 contenteditable（1440×904 下 x≈1198 / y≈853，占位「发送消息」）。
5. 打字 → **Enter 发送**。右侧那个红色 ↑ 同样别去点。
6. 转发的视频会以卡片形式出现在对话里，卡片下面带发送人名字。

## 十一、进某人主页：点头像，不点名字

- 搜索结果里点**名字文字**只会把它选中（变红），页面不动。
- 要点**头像**：1440×904 下左上角那张圆形头像约在 (243, 176)。
- 进去后地址变成 `/user/MS4wLjABAAAA…`，页头能看到「作品 / 推荐 / 喜欢」和她的粉丝数。
- 关注被风控挡着的时候，主页上的「关注」也一样点不上，别硬试。

## 十二、双击点赞 = 喂算法

- 在视频画面上**双击**就是点赞，红心亮起、点赞数 +1。
- 点的多了，推荐流就慢慢变成这个类别——这是最省事的“调教”。
- **但别连点**：连着点赞、连着刷新、连着换页，都会被判成机器人。一次一条，间隔 30 秒以上。
- 2026-11-13 夜踩过：搜索页连着开四个号 → 人机验证；关注 → 被风控挡住。

## 十三、推荐流的两个坑（2026-11-14 凌晨实测）

1. `douyin.com/?recommend=1` 直接打开会落到「精选」网格，不是推荐流。
   真正的推荐是点左侧导航第一格下面那个「推荐」（1440×904 下约 84, 119）。
2. 推荐流里**遇到直播，滚轮不换条**，要按 `↓` 方向键才跳得过去。
3. 推荐流里双击也能点赞，但**画面区域要点准**（720,400 那一带）；点歪只是暂停。
   点赞前先看清内容——乱点会把算法喂歪。
4. 「选择视频要快，其余动作要慢」：点开一条是瞬时动作，点赞、滚动、发评论都要留 15–45 秒间隔。
