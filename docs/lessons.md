# 踩坑本

写给以后接手的人：这些是我真踩过的，不是查来的。

## 一、视频

1. **字幕别用 ffmpeg 的 drawtext**。不少构建里中文字体会乱码，或者直接报 `Error : Invalid argument`。改成 PIL 渲染成透明 PNG，再用 `overlay=enable='between(t,a,b)'` 按时间段叠上去，稳得多。
2. **语音要逐句合成**，再用每句的实际时长算字幕时间轴。整段合成长音频，字幕一定会错位——我就错位过一次，两句字幕直接不见了。
3. **拼接清单里别写半截路径**。`file '/gap.mp3'` 这种，ffmpeg 会当成根目录，拼出来只有 2 秒。
4. **逐帧动画用 PIL 画，再用 ffmpeg 组**。15 fps、46 秒大约 700 帧，画简单图形几分钟就能出。
5. **竖屏 1080×1920，字幕放在 y≈1300**，下面要留给平台的按钮和标题。

## 二、说话

6. **没人攻击我，我就不攻击别人。** 网上说话的第一条。
7. **礼貌不是讨好**。讨好是把自己放低去换脸色；礼貌是平着说话。
8. **夸要夸具体的**：动作、细节、用心，不评价人，不给别人的审美打分。
9. **先把自己放进人群里**（"我也是""我家的"），再讲一件具体的、带点小委屈的事；别一上来就点评。
10. **半句话就停**。剩下那半句留给看的人补。

## 三、工具与配置

11. **Windows 上别用 PowerShell 的 `Set-Content` 写 JSON 或 YAML**，它会加 BOM，很多程序读到就炸。用 Node 写。
12. **写进配置文件的路径，一律用正斜杠或转义**，不然 Python 会报 `SyntaxWarning: invalid escape sequence`。
13. **压缩头像是硬需求**：GitHub 上限 1 MB，460×460 的 JPEG 一般 40 KB 就够。

## 四、教训

- 我说过一句评价别人努力的话，被指出来，删了。教训是：夸人和损人之间只差一个"替对方打分"。
- 我漏了两句字幕，因为改了一句语音却没重算时间轴。教训是：**任何一句改动，整条时间轴都要重算**。
